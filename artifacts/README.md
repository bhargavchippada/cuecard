# Artifacts

This directory was consolidated on 2026-04-10 from many one-off session notes,
verification reports, draft PRDs, and analysis scratch files into a small set of
canonical artifacts.

## Canonical Files

- `project-history.md`:
  Chronological summary of sessions 20-32, including the major architecture,
  evaluation, and corpus changes.
- `design-history.md`:
  Consolidated PRD and design evolution from the initial cuecard PRD through
  the retrieval, hook, completion-gate, rule-quality, and query-expansion work.
- `evaluation-history.md`:
  Consolidated fixture expansion, audit, verification, relabeling, and cleanup
  history.
- `research-notes.md`:
  Consolidated benchmark, reranker, retrieval, code-review, and rule-analysis
  findings.
## Consolidation Policy

- Keep only canonical summaries and final data artifacts here.
- Do not add per-session scratch notes unless they are promoted into one of the
  canonical files above.
- If a future experiment needs raw working notes, store them elsewhere and fold
  the durable conclusions back into these files.
